# QuickScan Camera

A Flutter app to capture multiple images and detect QR codes and barcodes.

## Features
- Custom camera with Start, Capture & Stop.
- Multiple image capture.
- QR and barcode scanning using Google ML Kit.
- Display and copy scanned data.
- Full-screen image preview with zoom.
- Camera permission handling.

## Tech Stack
Flutter, Dart, GetX, Camera, Google ML Kit.

## How It Works
Start → Capture Images → Stop → View Results.

## Run Project
```bash
flutter pub get
flutter run
```

## Build APK
```bash
flutter build apk --release
```
